# A1 结论：BPTT 会把一个"完美底座"打崩

> 日期：2026-11-14 深夜（overnight 第一批）
> 协议：`exp/evalkit.py`（裁切数据 / 固定分母 / 6 clip 分层）
> 目的：用**零蒸馏误差**的教师网络做底座，把"策略质量差"这个混杂因素彻底消掉

---

## 1. 结果

| 项 | 数值 |
|---|---|
| 教师底座起手（evalkit） | **0.3798**（存活 430/500） |
| BPTT 60 轮，3 个种子 | **0.0768 ± 0.0075**（0.0749 / 0.0851 / 0.0705） |
| 相对变化 | **−79.8%** |
| 单样本 t 检验（vs 起手） | t = −70.4，p = 2.0e-04 |
| 对照：零动作地板 | 0.0496 |
| 对照：PD | 0.0578 |

**3 个种子全部崩塌，且没有任何一个 checkpoint 超过起手**（脚本里 `best` 始终是 0.3798）。

---

## 2. 这条结果排除了什么

之前所有 BPTT 实验都建立在 **BC 学生**上（0.0912，存活 89/500）。观察到的 −26.6% 可以有两种解释：

1. 底座太弱，BPTT 在低信噪比轨迹上学不到东西；
2. WM 不够准，想象回报本身是错的。

**A1 排除了 (1)**：底座换成能跑满 430 步的教师（分数是学生的 4.2×），BPTT 依然把它打到接近零动作地板。

> 结论：**问题不在策略质量，在 WM。** 这一条现在有干净的证据。

---

## 3. 崩塌的形态

- 崩塌**很快**：约 10–20 轮内就到 0.07 附近。
- **想象回报 J 在上升，真值分数在下降**（J 从 ~1 涨到 ~5.3，分数从 0.38 掉到 0.07）——典型的模型利用（model exploitation）。
- 动作幅度检查：
  - 对 `p0_clean` 底座：BPTT 后平均 `|a|` 从 0.999 → 0.900（**−9.9%**）；
  - 对教师底座：BPTT 后平均 `|a|` 从 1.019 → 1.357（**+33.2%**）。
  - **方向相反** → 说明不是单一的"萎缩"或"放大"，而是**优化器跑向模型不准的动作区域**，方向取决于模型在该区域的具体缺陷。

---

## 4. 为什么信赖域没拦住

`kl_target=0.02` 约束的是**单轮**动作变化（实测 `dev` 稳定在 0.019–0.020）。但 60 轮累积漂移约 `√60 × √0.02 ≈ 1.1`（RMS），足以彻底改变策略。

**修法已实现**：`--anchor-init` 把信赖域锚定到**初始**策略（限制累积漂移而非单轮变化），已作为 C 阶段的对照配置之一。

---

## 5. 对后续的含义

| 问题 | 答案 |
|---|---|
| BPTT 能不能用？ | **在当前 WM 精度下不能**，与底座好坏无关 |
| 卡在哪？ | WM 在策略分布上的开环精度（on-policy `ratio32 ≈ 0.50`，只比 persistence 好 2 倍） |
| 下一步该做什么 | **阶段 B**：把 WM 修到 `ratio32 ≤ 0.25` 且误差不随动作幅度偏置（`mag_ratio ≤ 1.5`） |

---

## 6. 与前几轮的关系

之前"BPTT 在 BC 底座上 −26.6%"的结论**方向正确但归因不完整**——我们当时无法排除"底座太弱"。现在可以：

- **BC 底座**：−26.6%
- **教师底座**：−79.8%

底座越好，崩塌反而越明显（因为可失去的更多）。这进一步支持"想象回报本身有偏"这一解释。
