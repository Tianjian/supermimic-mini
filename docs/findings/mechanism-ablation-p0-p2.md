# P0–P2 实现与实验结果评审

> 日期：2026-11-15 上午
> 内容：把全局评审提出的三个"缺失零件"（P0 可微 bootstrap / P1 survival weight / P2 交错在线循环）全部实现并做消融
> 结论：**三个零件都实现了，但都没有带来增益。最好的一组（P0+P1+critic 预热）是 +0.4%（p=0.81），统计上与零无异。**

---

## 1. 实现清单（全部完成）

| 编号 | 内容 | 实现 | 默认 |
|---|---|---|---|
| **P0** | ∇θ 穿过 γ^H·ĉ_H·V(ŝ_H)，恢复论文的长程信度分配 | `--bootstrap-grad {0,1}` | 1 |
| **P1** | 可微 survival weight ĉ_t（与 env 终止条件同构：高度误差 >0.25 / 倾角 >0.8，sigmoid 软化） | `--survival {0,1}`、`--term-thresh`、`--tilt-thresh` | 1 |
| **P1b** | critic 每轮 5 epochs × 4 minibatches（论文值），每次 minibatch 重新前向 | `--critic-epochs`、`--critic-minibatches` | 5 / 4 |
| **P2** | 每 N 轮用当前策略采数据 + 微调 WM（固定数据 50/50 混合） | `--online-every`、`--online-size`、`--wm-steps` | 0（关） |
| **附加** | critic 预热：前 N 轮只训 critic、不动策略 | `--critic-warmup` | 0 |

P2 的机制已验证可用：`[P2 round k] 采 N 条 + 微调 S 步，WM loss …`。

## 2. 消融结果（教师底座，H=16，40 轮，3 种子，**固定 it20/it40 报数，不挑 best**）

| 配置 | it20 | it40 | 相对起手 0.3798 | p |
|---|---|---|---|---|
| A_old（P0/P1 关，critic 1 步） | 0.1346 | 0.1645 | −56.7% | 0.000 |
| **B_p0**（只开 P0） | 0.0899 | **0.0679** | **−82.1%** | 0.001 |
| C_p0p1（P0+P1+critic20） | 0.0753 | 0.1083 | −71.5% | 0.016 |
| D_p0p1_cl（C + 动作夹具 0.2） | 0.3700 | 0.3725 | −1.9% | 0.463 |
| E_p0p1_bc（C + BC 软正则 5） | 0.3870 | 0.3780 | −0.5% | 0.585 |
| F_full（C + 夹具 + P2 在线） | 0.3588 | 0.3689 | −2.9% | 0.157 |
| **W10（C + 夹具 + critic 预热 10 轮）** | — | **0.3811 ± 0.0086** | **+0.4%** | 0.811 |
| W20（预热 20 轮） | 0.3798 | 0.3723 ± 0.0108 | −2.0% | 0.353 |

**没有任何配置显著优于教师起手。最好的是 W10 的 +0.4%（p=0.81）。**

---

## 3. 四条实测结论

### 3.1 P0（可微 bootstrap）单独是**有害**的

- 梯度范数从 0.5 跳到 **3–6**；
- 不加重则时：A_old −56.7% → B_p0 **−82.1%**。

原因：critic 每次 run 从零训练、只做几十到几百次更新，它的 ∂V/∂s 基本是噪声。把噪声接进策略梯度，比不接更糟。

**critic 预热看似能救回一部分**（−1.9% → +0.4%），但补满种子后发现**效果非单调**：

| 预热轮数 | 结果 | 相对 |
|---|---|---|
| 0 | 0.3725 | −1.9% |
| 10 | 0.3811 ± 0.0086 | +0.4% |
| **20** | **0.3723 ± 0.0108** | **−2.0%** |

0 → 10 → 20 不是单调改善，说明 **+0.4% 也是噪声**。预热轮数对结果没有实质影响。

结论不变：**"精度不足"不是靠预热几十轮能补的**——论文的 critic 是在 32 万轮的同分布想象上长出来的。

### 3.2 P1（survival weight）在我们的场景里几乎是**惰性的**

实测 `d_mean ≈ 0.02`、`c_end ≈ 0.96–0.99`：soft 终止概率几乎不激活。

原因：想象 rollout 从教师能站住的起点出发，WM 在 16 步内预测的状态偏离不足以触发终止阈值。**它不是没用，而是"用不上"**——只有当策略开始往危险区域走时它才起作用，而那时夹具已经在拦着了。

### 3.3 P2（交错在线循环）**没有帮助**

- F_full −2.9%，比同样带夹具的 D（−1.9%）还略差；
- 每 10 轮采 5000 条 + 微调 300 步，WM loss 稳定在 0.19 左右，但没有转化为策略增益。

可能原因：10 轮 × 300 步的微调量太小，WM 的改进不足以改变 BPTT 的信噪比；而每次交错的开销（30 s）让总迭代变少。

### 3.4 唯一稳定的效应仍然是**正则化防崩**

- 夹具 0.2：−1.9%
- BC 软正则 5：−0.5%
- 二者 + P0/P1/P2 任意组合：都在 ±3% 内波动

**正则化能让 BPTT"不搞破坏"，但没让 BPTT"产生改进"。**

---

## 4. 这如何修正上一轮的"全局评审"结论

上一轮我说："我们为省算力拆掉了三个让 BPTT 稳定的零件，把它们装回去就能好。"

**这个判断被实验证伪了一半：**

- ✅ 零件确实被拆掉了——这点没错，现在都装回去了。
- ❌ 但装回去**并不会**让 BPTT 变好。

更准确的表述是：**这三个零件不是"独立的修复项"，而是"精度的放大器"**——它们假设 WM 和 critic 已经足够准，其梯度携带信号。在我们的预算下，它们携带的是噪声，于是放大器变成了噪声放大器。

所以对"是否算力所限"的最终回答是：

> **不是"算力不够导致我们跑不完"这么简单，而是"这三个机制本身依赖算力换来的精度"。** 在小预算下把它们装回去，效果是负的。

这与论文并不矛盾：论文的 3.2M WM 梯度步和 1.3B 想象样本，正是让这些机制从"噪声放大"变成"信号放大"的那个条件。

---

## 5. 现在还剩什么可做的

经过这一轮，可以排除的假设已经很多了：

| 已排除 | 证据 |
|---|---|
| 底座太弱 | A1：零蒸馏误差的教师也崩 |
| 视野太长 | H=4 仍崩 |
| WM 不够准 | 精度提升 3.2× 只把 −80% 挪到 −69% |
| 缺可微 bootstrap | 装上更差 |
| 缺 survival weight | 装上几乎不激活 |
| 缺在线循环 | 装上无改善 |
| 缺正则 | 正则是唯一有效项，但只防崩 |

**剩下的合理方向**（按性价比）：

1. **降低任务难度，换取可测量的增益空间**：现在是全身跟踪 + 平衡，教师 0.38 已接近上限，任何改进都被噪声淹没。换成一个**有余量的任务**（例如只跟踪上肢、或从"站立平衡"而非全身动作开始），BPTT 的增益才可能显现。成本 ~2 h。
2. **把 WM 的动作幅度偏置当主问题修**（`mag_ratio ≈ 4.1`，结构性）：这是唯一还没被充分攻过的定量缺陷。成本 ~3 h。
3. **接受结论，把项目定位改成"复现失败的可解释性研究"**：现在已经有一份相当完整的负面结果链条（capture→梯度→视野→精度→零件→正则），这本身是有价值的产出。

---

## 6. 一句话

**三个零件全装回去了，BPTT 还是没变好（最好 +0.4%，p=0.81）。** 这说明它们不是缺失的修复项，而是需要精度才能生效的放大器——而精度恰恰是小预算买不到的那部分。
